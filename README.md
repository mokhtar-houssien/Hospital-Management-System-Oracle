# مشروع نظام إدارة المستشفيات (Hospital Management System)

هذا المشروع عبارة عن قاعدة بيانات لنظام مستشفى تم بناؤها باستخدام لغة **SQL** وعن طريق برنامج **Oracle Database**.

---

2. **جدول الأطباء (DOCTORS):** لتخزين بيانات الأطباء وتخصصاتهم والقسم الذي يعملون فيه.
3. **جدول المرضى (PATIENTS):** لتخزين بيانات المرضى (الاسم، العمر، الجنس، العنوان).
4. **جدول المواعيد (APPOINTMENTS):** يربط المريض بالطبيب المعالج مع تاريخ وحالة الموعد.
5. **جدول الغرف (ROOMS):** لتخزين غرف المستشفى ونوعها وسعتها والجميع مرتبط بالأقسام.

---

## 🛠 المفاهيم التي تم تطبيقها:
- **المفاتيح الرئيسية (Primary Key):** لضمان عدم تكرار أرقام المرضى والأطباء والجداول.
- **التوليد التلقائي (Identity):** لإنشاء الأرقام التسلسلية تلقائياً.
- **المفاتيح الأجنبية (Foreign Key):** لربط الجداول ببعضها بشكل صحيح.
- **الشروط والقيود (Constraints):** مثل التأكد من العمر، وميزانية القسم، وتحديد الجنس (M/F).
- **الاستعلامات (JOIN):** لعرض بيانات المريض مع طبيبه في تقرير واحد.
